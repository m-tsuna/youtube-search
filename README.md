# youtube-search

YouTube Data API を使って、キーワードで動画を検索し、見つかった動画のタイトルと URL をターミナルに表示する Python プログラムです。

## 何をするものか

1. `.env` に書いた API キーを読み込む
2. 検索キーワードを入力し、並び順（関連度順・新しい順）を選ぶ
3. YouTube Data API で、動画を最大10件検索する
4. 番号・タイトル・URL を表示する

```
% python main.py
検索キーワードを入力してください: 猫 かわいい
並び順を選んでください: 1. 関連度順  2. 新しい順
番号（Enter だけなら 関連度順）: 2

「猫 かわいい」の検索結果（新しい順・10件）
------------------------------
1. 子猫がはじめて雪を見た日
   https://www.youtube.com/watch?v=xxxxxxxxxxx
2. ...
------------------------------
```

## 事前準備

### 1. ライブラリのインストール

```bash
pip install google-api-python-client python-dotenv
```

### 2. Google Cloud Console の設定

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを選ぶ（なければ作る）
2. 「API とサービス」→「ライブラリ」で **YouTube Data API v3** を検索して「有効にする」
3. 「API とサービス」→「認証情報」→「認証情報を作成」→「API キー」でキーを作る
4. 作ったキーの編集画面で「API の制限」→「キーを制限」→ **YouTube Data API v3** だけにチェックして保存する

公開されている動画を検索するだけなので、ログイン（OAuth）は使いません。

## 秘密ファイルの用意の仕方

API キーは GitHub に載せていません（`.gitignore` で除外）。自分で用意してください。

| ファイル | 中身 | 用意の仕方 |
|---|---|---|
| `.env` | YouTube Data API の API キー | `.env.example` をコピーして `.env` という名前にし、`YOUTUBE_API_KEY=` の後ろに上で作ったキーを書く |

`.env` の例：

```
YOUTUBE_API_KEY=AIza...（自分のキー）
```

## 使い方

```bash
python main.py
```

- キーワードは日本語でも英語でも、複数の単語（`猫 かわいい` など）でも検索できます
- 並び順は番号で選びます。何も入力せずに Enter なら関連度順です
- 表示する件数は、`main.py` の先頭の `MAX_RESULTS` で変えられます（1〜50）
- 見られない動画などを YouTube が除くため、10件より少なく表示されることがあります
- 再生回数の多い順は、YouTube の検索が正確に並べないため、選択肢に入れていません
- 途中でやめたいときは Ctrl + C を押してください

## 使える回数（割り当て）

- YouTube Data API は、1日に使える量（既定で 10,000 ユニット）が決まっています。無料です
- 検索は1回 100 ユニットなので、**1日に約100回**まで検索できます
- 割り当ては毎日、太平洋時間の0時（日本時間の16時か17時）にリセットされます

## 安全のための工夫

- API キーはコードに書かず、GitHub に載せない `.env` に書きます
- API キーは YouTube Data API v3 だけに使えるよう制限します（漏れたときの被害を小さくするため）
- 検索するだけで、YouTube 上のものは何も変えません

## うまくいかないとき

| 表示 | 対処 |
|---|---|
| API キーが設定されていません | `.env` を作り、`YOUTUBE_API_KEY=` の後ろにキーを書く |
| API キーが正しくありません | `.env` のキーが Google Cloud Console のキーと同じか確かめる |
| YouTube Data API を使う許可がありません | YouTube Data API v3 を有効にする。API キーの制限に YouTube Data API v3 が入っているか確かめる |
| 今日の検索できる回数を使い切りました | 翌日のリセットを待つ |

詳しい仕様は [要件定義書.md](要件定義書.md) を見てください。
